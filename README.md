# SECCON BadUSB Workshop

RP2040 搭載 SECCON バッジで **BadUSB(Rubber Ducky 型の HID 注入デバイス)** を自作し、
「USB メモリの顔をしたデバイスが、なぜ・どこまで危険になり得るのか」を **手を動かして理解する** 半日ワークショップの教材集です。

攻撃手法の習得ではなく、**仕組みの理解と、検知・防御・自衛** を目的としています。

---

## ⚠️ 倫理・法的注意(最初に必ず読む)

> - すべての演習は **自分が所有・管理する機材、または明示的に許可を得た検証環境** に対してのみ行ってください。
> - 他人の PC・共有 PC・業務端末に無断でデバイスを挿す行為は、**たとえ無害なペイロードでも**、
>   不正指令電磁的記録に関する罪、不正アクセス禁止法違反、業務妨害、社内規程違反などに該当し得ます。
> - 教材のペイロードは **すべて非破壊・可逆**(アプリを開く / 固定メッセージを打つ程度)に留めます。
>   PowerShell・コマンドプロンプト・任意コマンド実行・ダウンロード・削除・設定変更・認証情報取得は扱いません。
> - デバイスには **アーム用スイッチ(GPIO ジャンパ)** を実装し、普段はただの USB メモリとして振る舞い、
>   明示的にアームした時だけデモが発火する設計にします。
> - 導入教材の買い物演習(資料3)は **カートに入れるところまで**。実際の購入・注文はしません。
>
> この教材の裏の狙いは、**「出所不明の USB を挿さない」「離席時は画面をロックする」** を体で理解することです。

## 教材の構成

このワークショップは **2段階** で構成されます。
まず導入(ジグソー法)で「キーボードだけで何ができるか」を体感し、その気づきを土台に本編でデバイスを自作します。

### 1. 導入 ── ジグソー教材(キーボードだけで何ができるか)

協調学習(ジグソー法)で、参加者が別々の資料に取り組み、発見を持ち寄ります。

| 資料 | テーマ | 要点 |
|---|---|---|
| [導入ワークシート](jigsaw-worksheet.md) | 判断の可視化 | 「その USB、挿しますか?」を活動の前後で書き、判断の変化を見る |
| [資料1 キーボードだけで OS 操作](jigsaw-1-keyboard-only.md) | OS 操作 | マウスなしでウィンドウ操作・アプリ起動ができる |
| [資料2 開発環境なしでプログラム実行](jigsaw-2-compile-without-ide.md) | コード実行 | 重い IDE なしでも、素の環境でプログラムを書いて動かせる |
| [資料3 マウスなしで Web 操作](jigsaw-3-keyboard-web.md) | Web 操作 | Tab / Enter だけで検索・フォーム・カート投入まで届く |

> **論理の筋**: 「OS 操作 → プログラム実行 → Web 操作」がすべてキーボードだけで完結する、と分かると、
> 「HID キーボードとして振る舞う BadUSB がなぜ脅威なのか」が自分の言葉で説明できるようになります。

### 2. 本編 ── BadUSB ハンズオン(バッジで自作する)

導入で得た理解を土台に、RP2040 バッジで HID キーボード + USB マスストレージの複合デバイスを作ります。

| ハンドブック | 標的 OS | デモの範囲 |
|---|---|---|
| [macOS 版ハンドブック](seccon-ws-badusb-rp2040.md) | macOS | Spotlight でアプリ起動(電卓 / TextEdit)まで |
| [Windows 版ハンドブック](seccon-ws-badusb-rp2040-windows.md) | Windows 10 / 11 | Notepad を開いて固定メッセージを打つのみに限定 |

各ハンドブックは、環境準備 → コンポジットデバイスの理解 → キー入力 → 標的ペイロード(無害)→
マウント時の確実な発火 → アーム用スイッチ → レイアウトの罠 → **守り側の検知と防御** → 発展課題、の順で進みます。

## 進め方(推奨フロー)

1. **導入(§ジグソー)**: [ワークシート](jigsaw-worksheet.md)の設問1(活動前の直感)を書く。
2. 参加者が資料1〜3のいずれかに取り組み、グループで発見を共有する。
3. **本編ハンズオン**: 自分の OS に合うハンドブック(macOS / Windows)でデバイスを自作する。
4. **守り側の議論**: 検知・防御パートで「どう身を守るか」を話し合う。
5. **振り返り**: ワークシートの設問5(活動後の直感)を書き、設問1と見比べる。

## 必要なもの(講師)

- RP2040 SECCON バッジ(人数分)+ **データ通信対応** USB ケーブル(充電専用ケーブル厳禁)
- 参加者 PC(macOS または Windows 10/11)
- CircuitPython の UF2 と Adafruit ライブラリバンドルを **オフライン配布**(会場 Wi-Fi を当てにしない)
- ジャンパワイヤ or タクトスイッチ(アーム用)。バッジ上の空きピン/ボタンで代替可
- (Windows でプログラム実行演習を行う場合)Python を事前導入した検証端末
